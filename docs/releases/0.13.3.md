DOKK 0.13.3, Build 44.

## Verbesserungen

- DOKK sendet anonyme Nutzungsdaten an PostHog in der EU-Cloud. Die Daten zeigen, welche Funktionen genutzt werden, in welcher Konfiguration, in welchem Dock-Modus und mit welchem Erscheinungsbild.
- Anonyme Nutzungsdaten teilen ist in 0.x standardmäßig an. Ausschalten kannst du das unter Einstellungen › Allgemein › Datenschutz. Die Erfassung stoppt sofort. DOKK löscht Ereignisse, die noch nicht hochgeladen wurden.
- Dieselbe Karte hat den Schalter Anonymes Profil führen. Er ist deaktiviert, solange Anonyme Nutzungsdaten teilen aus ist. In der Zeile Anonyme ID ersetzt Zurücksetzen die zufällige ID.
- Eine Neuinstallation sieht in der Tour beim ersten Start die Informationsseite Anonyme Nutzungsdaten. Bei einer Neuinstallation sendet DOKK erst, nachdem diese Seite oder die Karte Datenschutz auf dem Bildschirm war. Wer von einer Version ohne diese Erfassung aktualisiert, erhält keinen zusätzlichen Hinweis.
- Nicht erfasst werden App-Namen und Bundle-IDs, Symbole, Dateinamen, Pfade, Dateiinhalte, Fenstertitel, Webadressen, Suchtext aus Launcher und Suche, Namen, die du eintippst, und Inhalte der Zwischenablage.
- Ausnahme: Wenn du eine Apple-Intelligence-Funktion nutzt, werden Anfrage und Antwort vollständig geteilt.
- Ein Build ohne Token sendet nichts. Die Karte meldet dann "Dieser Build sendet keine Nutzungsdaten."

## English

DOKK 0.13.3, Build 44.

### Improvements

- DOKK sends anonymous usage to PostHog on the EU cloud. The data shows which features are used, in which configuration, Dock Mode, and appearance.
- Share anonymous usage data is on by default during 0.x. You can turn it off in Settings › General › Privacy. Collection stops at once. DOKK deletes events that are not uploaded yet.
- The same card has the switch Keep an anonymous profile. It is disabled while Share anonymous usage data is off. On the Anonymous ID row, Reset replaces the random ID.
- A new install sees the informational page Anonymous usage data in the first-launch tour. For that install, DOKK sends nothing until that page, or the Privacy card, has been on screen. People updating from a version without this collection get no extra notice.
- DOKK does not collect app names and bundle IDs, icons, file names, paths, file contents, window titles, web addresses, Launcher and search query text, names you type, or clipboard contents.
- Exception: when you use an Apple Intelligence feature, its request and its answer are shared in full.
- A build with no token sends nothing. The card then says "This build does not send usage data."
