DDock 0.9.3, Build 34.

## Fehlerbehebungen

- Window Peek: das Panel behält die berechnete Größe; Karten werden nicht mehr auf die Ladehöhe zugeschnitten.
- Window Peek: Rollbalken bleiben ausgeblendet (auch bei „Immer anzeigen“), damit sie den Karten keinen Platz wegnehmen.

## Verbesserungen

- Einstellungen › Window Peek › Diagnose: Diagnose kopieren (Größen und Skalierung; keine Titel, App-Namen oder Bilder).
- Info / Versionszeile zeigt den kurzen Git-Commit des Builds.

## English

DDock 0.9.3, Build 34.

### Bug Fixes

- Window Peek: the panel keeps its computed size; cards are no longer clipped to the loading-state height.
- Window Peek: scroll indicators stay hidden (even with “Show scroll bars: Always”), so they don’t take space from the cards.

### Improvements

- Settings › Window Peek › Diagnostics: Copy Diagnostics (sizes and scale only; no titles, app names, or images).
- About / version line shows the short git commit of the build.
