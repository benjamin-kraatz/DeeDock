# DDock 0.11.2 What’s New

**In Ablage legen**

Comic for the [DOKK 0.11.2 release notes](0.11.2.md). Review preview: [0.11.2-comic.html](0.11.2-comic.html).

## Panel 01 — Ordnermenü

![Eine lächelnde Download-Schale und ein angehefteter Ordner zeigen ein leeres Menü mit einer markierten Zeile.](assets/0.11.2/panel-01.png)

**Menü am Ordner**

> Schau ins Menü.

Downloads und angeheftete Ordner zeigen den Befehl auch für Inhalte.

## Panel 02 — Befehl wählen

![Ein lächelnder Zeiger wählt die markierte Menüzeile mit einer kleinen Ablage-Schale. Ordner und Datei bleiben stehen.](assets/0.11.2/panel-02.png)

**In Ablage legen**

> Nur ein Verweis.

Wähle den Befehl für den Ordner oder eine Datei darin. Nichts wird verschoben oder kopiert.

## Panel 03 — Verweis

![Eine lächelnde Marke ruht auf der Ablage-Schale. Der Ordner bleibt an seinem Platz, verbunden durch eine gepunktete Linie.](assets/0.11.2/panel-03.png)

**Der Verweis bleibt**

> Ich bleibe hier.

Auf der Ablage liegt ein Verweis. Die Datei bleibt an ihrem Ort.

## English

**Add to Shelf**

### Panel 01 — Folder menu

![A smiling Downloads tray and a pinned folder show a blank menu with one highlighted row.](assets/0.11.2/panel-01.png)

**Menu on the folder**

> Open the menu.

Downloads and pinned folders show the command for their contents too.

### Panel 02 — Choose the command

![A smiling pointer chooses the highlighted menu row with a small Shelf tray. The folder and file stay put.](assets/0.11.2/panel-02.png)

**Add to Shelf**

> Just a reference.

Choose it for the folder or a file inside. Nothing is moved or copied.

### Panel 03 — Reference token

![A smiling token rests on the Shelf tray. The folder stays in place, joined by a dotted line.](assets/0.11.2/panel-03.png)

**The reference stays**

> I stay put.

A token sits on the Shelf. The file stays where it lives.
