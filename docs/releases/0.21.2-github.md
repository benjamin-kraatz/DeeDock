DOKK 0.21.2, Build 67.

### New

- In the Hub's Files tab, middle-clicking a folder opens it in a new browser tab. This works in list, icon, and column view, in the sidebar, and on breadcrumb segments. If a visible pane in any tab already shows that folder, DOKK switches to it instead.
- Shift-middle-click opens the folder in a background tab and leaves the current tab, its panes, and any search alone.
- Radar can show or hide app names in its running-app strip: Settings → Windows & Focus → Radar → **Show app names in the strip**. Names are off by default, and the strip uses the space they free.
- DOKK Islands can show or hide the lit line along the screen edge: Settings → Features → DOKK Islands → Look → **Lamp**, with **Lamp thickness** and **Lamp opacity**. The lamp is on by default. Turning it off removes the line, and the glow inside the glass stays. These controls apply to Ice block only.

### Fixes

- The Hub no longer flashes brighter or dimmer when you switch to or from the Files tab.
- In the Files tab, rows no longer stay highlighted after they scroll past a stationary pointer.
