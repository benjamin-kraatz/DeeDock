DOKK 0.18.0, Build 56.

### New

- Radar shows every window in the current Space at once, grouped by app. Open it with Option-Shift-Command-Space from any app, with "Show Radar" in the DOKK menu, or with the Radar tile. The tile is off by default. Turn it on in Settings › Windows & Focus › Radar, where you can also turn off the shortcut. If another app already uses the shortcut, Settings says so.
- Radar covers each display with its blurred wallpaper and flies the windows into groups by app. The most recently used app leads in its own row with larger thumbnails. The dock transforms along with it: apps that are not running and the Trash step aside, and the running apps show their names and window counts. Minimized windows and windows of hidden apps appear as small chips inside their app's group.
- Click a window, or pick it with the arrow keys and Return, to bring it forward. Hovering a window shows a Close button. If the window stays open, for example because a save dialog appears, Radar steps aside and brings it forward. Typing filters by window title and app name. Clicking an app in the dock shows only its group. Escape clears the search, then the filter, then closes Radar.
- Radar never hides or minimizes apps; it only draws over them. With Accessibility, Radar brings single windows forward and closes them. Screen Recording adds thumbnails, which stay in memory only while Radar is open. Windows on other Spaces and in other full-screen Spaces are not shown. Reduce Motion replaces the flight with crossfades, and Reduce Transparency makes the backdrop, groups, and dock opaque.
- Usage analytics count how often Radar opens and how it ends. Window titles, search text, and app names are not sent.
