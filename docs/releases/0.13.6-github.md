DOKK 0.13.6, Build 47.

### Improvements

- Focus Sessions: under an hour the countdown stays minutes and seconds, through 59:59. At an hour or more it shows hours as well, such as 1:30:05. VoiceOver speaks the remaining time with the phase.
- Folder stacks read a PDF page count without loading the whole PDF.
- Folder stacks remember image sizes, page counts, and durations for a limited number of files.
- A large folder stack shows the list at once. File icons fill in afterwards, so the dock does not wait for every icon.
- While Ask about suggestion quality is on in Settings › Features › App suggestions, App Launcher shows a short, optional survey under the suggestions after some use. It appears only while Share anonymous usage data is on. The answers go with that usage data.
- For the week around 14 February, 21 July, 22 August, and 14 November, the menu bar, menus, Settings, and About call DOKK BIG DIKK. The week is that date and the three days on either side. The app file stays DOKK.app.
- DOKK records more of how the app is used, including checking for an update, downloading it, and installing it. Settings › General › Privacy also says whether DOKK has Accessibility and Screen Recording access. Share anonymous usage data and Keep an anonymous profile stay on in this cut and cannot be switched.

### Fixes

- Clipboard Museum saves the catalog before it deletes an exhibit's files. If that save fails, the files stay until a later save succeeds.
- App badges read Dock badges off the work that draws the dock. A slow Accessibility reply no longer holds the dock.
- DOKK Discovery: a tip snoozed with Tomorrow does not block the tips behind it, and skipping it does not use up the wait before the next tip.
- A folder that differs only by letter case counts as the same folder. Copy, move, and closing a volume stack on eject recognize it.
- What's New: a comic from an update does not load images from files on this Mac. A comic opened from a local file shows only images inside that comic's folder.
