DOKK 0.12.1, Build 40.

## Verbesserungen

- Feste externe Festplatten brauchen eine Bestätigung vor dem Auswerfen. Die Karte zeigt deshalb einen kompakten roten Auswerfen-Knopf nur als Symbol, statt eines beschrifteten Knopfs über die volle Breite. „Im Finder öffnen“ nutzt den frei gewordenen Platz. Wechselmedium, Disk-Image und Netzwerkvolume behalten den beschrifteten Knopf.

## English

DOKK 0.12.1, Build 40.

### Improvements

- Fixed external disks need confirmation before eject, so their card shows a compact red icon-only eject button instead of a full-width labeled button. Open in Finder takes the freed space. Removable media, disk images, and network volumes keep the labeled eject button.
