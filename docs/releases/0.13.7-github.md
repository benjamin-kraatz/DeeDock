DOKK 0.13.7, Build 48.

### Improvements

- A folder or volume stack opens without holding the dock. A file dropped on a tile still copies if the stack closes before it finishes opening. Quick Look stays up when the list reloads.
- Clipboard Museum shows file tiles with a placeholder first. File icons fill in afterwards, so a slow file does not hold selection or the slideshow.

### Fixes

- Focus Sessions: in the session window, VoiceOver speaks the remaining time in words, such as twenty-five minutes. The digits stay 25:00, or 1:30:05 once an hour remains, and they keep counting each second. With Boss Fight, VoiceOver speaks that time and then remaining.
- Clipboard Museum no longer crashes when an image declares a huge width and height. Those images, and images with no valid size, are refused.
- Clipboard Museum: if redacting fails, the exhibit and its file stay. Settings shows "The collection could not be saved."
- Two files in one drop that differ only by letter case are no longer partly moved. If the volume treats those names as the same, the drop stops and both source files stay. If it treats them as different, both files arrive.
- Quarantine stamp: a stamped folder also covers a symlink to it, a file inside it, and a path that differs only by letter case. Opening stays blocked until the mark is released.
- Sleep, display sleep, and a user switch no longer clear app badges or reset the 15 seconds. Afterwards the last badges stay until a read succeeds or the remaining time runs out.
- App badges match the same app when the Dock path and the pinned path differ, such as /Applications/Safari.app and /System/Applications/Safari.app, or differ only by letter case. Saved badges are kept and assigned to the real path once, at launch.
- Window menus, Window Peek, Session Capsules, Find a Window, and App Fusion read Accessibility off the work the rest of DOKK shares. A slow reply no longer holds DOKK.
