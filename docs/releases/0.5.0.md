DDock 0.5.0, Build 23, benötigt macOS 27 und einen Mac mit Apple Silicon.

## Neue Funktionen

- Focus-Schulden-Meter: optionales Zählen abgebrochener Fokus-Sessions, lokal und abschaltbar.
- Shelf-Kompost: alternde Shelf-Einträge archivieren (7/14/30 Tage) und wiederherstellen — Dateien bleiben unberührt.
- Rezept-Snapshot: aktuellen Workspace als editierbaren Modus-Entwurf speichern.
- Split-Peek: zwei Fenster derselben App nebeneinander in Window Peek (standardmäßig aus).
- Focus-Atmung: optionales sanftes Atmen-Highlight im Dock-Hintergrund.
- Peek-OCR-Historie: lokale Texterkennung vergangener Peeks (Bilder werden nicht gespeichert).
- Patch-Bay: scoped Kabel von App-Pins zu Ordner-Pins (Finder ohne Aktivierung; standardmäßig aus).
- Icon-Gossip: opt-in KI-Tratsch zwischen Pins mit Intensitätsregler (Apple Intelligence, lokal).

## English

DDock 0.5.0, Build 23, requires macOS 27 and an Apple Silicon Mac.

### New

- Focus debt meter: optional local count of broken Focus sessions, off by default.
- Shelf Compost: archive aging Shelf entries (7/14/30 days) and restore them — original files untouched.
- Recipe snapshot: capture the current workspace into an editable Dock Mode draft.
- Split-peek: two same-app windows side by side in Window Peek (off by default).
- Focus breathing: optional soft breathing highlight in the dock background.
- Peek OCR history: local text from past peeks (images are never saved).
- Patch bay: scoped cables from app pins to folder pins (Finder without activation; off by default).
- Icon gossip: opt-in on-device AI chatter between pins with an intensity slider.
