DOKK 0.14.0, Build 50.

### New

- Settings › Dock › Appearance › Icon style adds "Line". Known apps and DOKK's own tiles draw white line glyphs instead of app artwork. An app with no glyph keeps its own icon. Hover and keyboard focus add a colored glow. Each display chooses its own style. Reduce Transparency drops the glow and draws the glyph brighter. Reduce Motion shows the glow without a fade.
- "Line icons in Launcher" is on by default while Line is selected. The same glyphs appear on Launcher tiles, in search rows, and in the "Open with this app" list, in the system text color.
- Appearance › Launcher adds "Full" and "Compact". Compact opens a small searchable app grid above the Launcher tile and leaves the dock in place. Dropped files always open the full Launcher. Each display chooses its own style.
- The glyph licenses are credited on the "Acknowledgements" card in Settings › General › About.
- Settings › Behavior, and the tour page "Move the macOS Dock aside", add "Tuck Away macOS Dock". DOKK hides the macOS Dock, shrinks it as small as it can, moves it to the side DOKK is not using, and restarts the Dock briefly. It stays hidden until the pointer rests on that edge for 10 seconds.
- "Restore macOS Dock", and every normal quit, put your settings back. The switch stays on, and the next launch tucks the Dock away again. If your organization manages the macOS Dock's settings, DOKK changes nothing.
