DOKK 0.26.1, Build 77.

## Neue Funktionen

- Window Peek zeigt auf Wunsch die aktuelle CPU-Last, den Speicher und die Netzwerkrate (empfangen und gesendet) einer App unter ihrem Namen. Einschalten unter Einstellungen → Funktionen → Window Peek → „CPU, Speicher und Netzwerk anzeigen“. Standardmäßig aus.
- Gemessen wird nur, solange der Peek offen ist; beim Schließen stoppt die Messung. Es gibt keinen Verlauf, dafür bleibt App Health zuständig. Der Speicher erscheint sofort, CPU und Netzwerk nach etwa einer Sekunde.
- Die Netzwerkwerte gibt es nur unter macOS 27. Hilfsprozesse wie Safaris WebContent-Prozesse werden wie in App Health nicht mitgezählt, daher kann die Rate eines Browsers niedriger sein als in der Aktivitätsanzeige.

## English

### New features

- Window Peek can now show an app's current CPU use, memory, and network rate (down and up) under its name. Turn it on in Settings → Features → Window Peek → “Show CPU, memory, and network”. Off by default.
- Sampling runs only while the Peek is open and stops when it closes. There's no history; App Health still covers that. Memory shows right away, CPU and network after about a second.
- Network figures are available on macOS 27 only. Helper processes such as Safari's WebContent processes aren't counted, same as App Health, so a browser's rate can read lower than in Activity Monitor.
