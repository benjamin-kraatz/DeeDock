DOKK 0.11.0, Build 36.

## Neue Funktionen

- Die App heißt jetzt DOKK (Anzeigename, Wordmark und Texte). Repo und Modul bleiben DeeDock; die Release-Bundle-ID ist unverändert.
- Window Peek: Speichern aus der vergrößerten Vorschau ohne Speicherpanel. Mit Shelf-Kachel: Datei in den Markup-Ordner und Flug aufs Shelf (Bounce beim Landen). Shelf aus → Downloads. Reduce Motion / ohne Kachel → Häkchen vor Ort. Fehler erscheinen am Dock; die geschriebene Datei wird dann entfernt.

## English

DOKK 0.11.0, Build 36.

### New

- The app is now named DOKK (display name, wordmark, and strings). Repo and module stay DeeDock; the Release bundle ID is unchanged.
- Window Peek: Save from the enlarged preview with no save panel. With the Shelf tile on, the file goes to the markup folder and flies onto the Shelf (bounce on land). Shelf off → Downloads. Reduce Motion / no tile → a checkmark in place. Failures surface on the dock and remove the written file.
