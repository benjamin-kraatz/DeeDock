DOKK 0.24.2, Build 73.

## Neue Funktionen

- Das Kontextmenü einer laufenden App zeigt jetzt auch die eigenen Dock-Menüeinträge der App, zum Beispiel „Open Developer Tool“ in Xcode. Sie stehen unter der Fensterliste, Untermenüs inklusive.
- Die Einträge erscheinen, solange das macOS-Dock weggeklappt ist. Ist das macOS-Dock sichtbar, öffnet sich das gewohnte Menü ohne diese Einträge.
- Kann DOKK die Einträge nicht schnell genug lesen, öffnet sich ebenfalls das gewohnte Menü, ohne Wartezeit.

## English

### New features

- A running app's context menu now also shows the app's own Dock menu items, like "Open Developer Tool" in Xcode. They sit below the window list, submenus included.
- The items appear while the macOS Dock is tucked away. When the macOS Dock is visible, the usual menu opens without them.
- If DOKK can't read the items quickly enough, the usual menu opens too, with no waiting.
