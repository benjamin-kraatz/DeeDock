DOKK 0.13.0, Build 41.

## Neue Funktionen

- Ein Laufwerk lässt sich auf jedem Dock ausblenden. Das Kontextmenü bietet "Im Dock ausblenden", und das Auge unter Einstellungen › Dock-Extras › Laufwerke blendet es ebenfalls aus. Das Laufwerk bleibt verbunden. Seine Karte und ein offener Stapel schließen sich.
- Ziehen einer Laufwerkskachel zwischen die anderen Laufwerke ändert die Reihenfolge. Dasselbe gilt für ihre Zeile in den Einstellungen. Ziehen ganz aus dem Dock wirft das Laufwerk weiterhin aus.
- Time Machine-Backup-Laufwerke bleiben aus dem Dock, bis "Time Machine-Backups anzeigen" in demselben Bereich an ist. Die Vorgabe ist aus. Ein Backup-Laufwerk fragt vor dem Auswerfen, wie andere feste Festplatten.
- Ein Ordnerstapel, den macOS nicht auflistet, zeigt "Kein Zugriff", dazu "Im Finder öffnen" und "Erneut versuchen". "Einstellungen für Festplattenvollzugriff …" erscheint nur, wenn Datenschutz den Zugriff sperrt. Das gilt für jeden Ordnerstapel, nicht nur für Backup-Laufwerke.

## English

DOKK 0.13.0, Build 41.

### New

- You can hide a drive from every dock. The context menu offers Hide from Dock, and the eye in Settings › Dock Extras › Drives hides it too. The drive stays mounted. Its card and any open stack close.
- Drag a drive tile among the other drives to reorder them, or drag its row in Settings. Pulling a tile clear of the dock still ejects.
- Time Machine backup disks stay off the dock until Show Time Machine backups, in that same Settings section, is on. The default is off. A backup disk still asks before eject, like other fixed disks.
- A folder stack that macOS refuses to list shows No access, with Open in Finder and Retry. Full Disk Access Settings… appears only when the refusal is privacy protection. This applies to any folder stack, not only backup disks.
