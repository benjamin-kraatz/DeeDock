DDock 0.10.0, Build 35.

## Neue Funktionen

- Window Peek Markup: Fenster aus Peek markieren (Stift, Text, Schwärzen, Zuschneiden, Export). Hero-Toolbar am vergrößerten Vorschaubild für Markieren, Kopieren und Speichern.

## Verbesserungen

- Debug- und Preview-Builds nutzen die eigene Bundle-ID `de.benjaminkraatz.DeeDock.dev` und den Namen „DDock Dev“, damit macOS-Freigaben die Release-App nicht überschreiben. Release bleibt unverändert.

## English

DDock 0.10.0, Build 35.

### New

- Window Peek Markup: annotate a Peek window (draw, text, redact, crop, export). Hero toolbar on the enlarged preview for Mark up, Copy, and Save.

### Improvements

- Debug and Preview builds use their own bundle ID `de.benjaminkraatz.DeeDock.dev` and the display name “DDock Dev”, so macOS privacy grants no longer replace the Release app’s. Release is unchanged.
