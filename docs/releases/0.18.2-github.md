DOKK 0.18.2, Build 58.

### New

- Folder stacks, including the Downloads and drive stacks, have Copy Path and Copy Relative Path in each item's context menu. Copy Path copies the full path as text, without a trailing slash on folders. Copy Relative Path starts at the stack's folder, not at the subfolder you are browsing: `file.txt` in Downloads copies `./file.txt`, and a file inside `folder` on a drive copies `./folder/file.txt`. This holds even when the stack's folder is reached through a symlink. With an item selected, Option-Command-C copies its path and Option-Shift-Command-C its relative path.
- The Shelf has the same two commands and shortcuts. They act on the whole selection and copy one line per item, using each item's current location. Shelf items come from many folders, so a relative path is `./name` within the item's own folder. Option-Command-C on the Shelf used to copy the files themselves; it now copies their paths.
- Usage analytics count path copies. Paths and file names are not sent.

### Improvements

- Four more apps have Line icons: Desk View, Unity Bug Reporter, Folder Actions Setup, and Expansion Slot Utility. Desk View gets a new hand-drawn glyph, a display on a stand above a desk. Each of the four icons has its own motion.
