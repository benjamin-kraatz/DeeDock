DDock 0.7.1, Build 27, benötigt macOS 27 und einen Mac mit Apple Silicon.

## Neue Funktionen

- Peek: Vorschauen in Fensterportale ziehen. Herausziehen pinnt ein Live-Portal. Beim Ablegen die Wahltaste halten für ein Standbild.

## English

DDock 0.7.1, Build 27, requires macOS 27 and an Apple Silicon Mac.

### New

- Peek: drag previews into window portals. Drag out to pin a live portal. Hold Option at drop for a frozen reference.
