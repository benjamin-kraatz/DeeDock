DOKK 0.15.0, Build 51.

### New

- The Notification Feed keeps the banners macOS shows, so you can read them after they disappear. It is off by default. Turn it on in Settings › Features › Notification Feed › "Collect notifications", and allow Accessibility access there. A DOKK Discovery tip on first launch also offers "Turn On".
- A bell tile appears after the Shelf on every dock. Its badge counts what arrived since you last opened the feed, and it rings once when a banner arrives. Reduce Motion skips the ring. The tile moves like Shelf and Downloads.
- Each entry shows the sending app, when it arrived, and the banner's title, subtitle, and text. Click an entry to open the app. Its context menu offers "Copy Text" and "Remove", and "Clear All" empties the feed. Keyboard and VoiceOver work throughout.
- Only banners that appear on screen are collected. Notifications held back by a Focus, set to show no banners, or arriving while the screen is locked are missing.
- The text stays in memory on this Mac. DOKK never saves it to disk, logs it, or sends it anywhere, and usage analytics never include it. The feed keeps the 100 most recent entries. Turning it off or quitting DOKK clears it.
