DOKK 0.13.2, Build 43.

## Verbesserungen

- Der Launcher blendet Apps aus, die unter dem Ordner einer anderen App liegen, etwa UnityPlayer.app-Vorlagen unter einem Unity-Editor. Unter /Applications oder ~/Applications gilt eine App als verschachtelt, wenn ein Ordner über ihrem eigenen Elternordner direkt eine andere .app enthält. Verschachtelte Apps fehlen in der App-Liste, in der App-Suche und bei Robi fragen. Geschwister bleiben sichtbar, etwa Unity Bug Reporter.app neben Unity.app. /Applications/Utilities/Terminal.app bleibt sichtbar.
- Verschachtelte Apps anzeigen ist ein Markierungsfeld in einem eigenen Abschnitt des Menüs Suchoptionen, über Auf Standard zurücksetzen. Es ist standardmäßig aus, gilt nur für diese Sitzung, und Auf Standard zurücksetzen schaltet es aus.
- Robi fragen kennt die Dateitypen jeder App und lässt allgemeine Datenformate aus. Eine kurze Beschreibung kommt zuerst aus dem Homebrew-Cask-Katalog, dann aus dem Mac App Store für dort installierte Apps, dann aus einer kuratierten Liste. Apps, die zur Aufgabe passen, stehen über Apps, die nur die Kategorie teilen.
- Einstellungen › Info hat die Karte Danksagungen. Sie nennt die Daten aus dem Homebrew-Cask-Katalog unter der BSD-2-Clause-Lizenz.

## English

DOKK 0.13.2, Build 43.

### Improvements

- The Launcher hides apps nested below another app's folder, such as UnityPlayer.app templates under a Unity Editor folder. Under /Applications or ~/Applications, an app is nested when a folder above its own parent directly holds another .app. Nested apps stay out of the app list, app search, and Ask Robi. Siblings stay visible, such as Unity Bug Reporter.app next to Unity.app. /Applications/Utilities/Terminal.app stays visible.
- Show Nested Apps is a checkbox in its own section of the Search options menu, above Reset to Defaults. It is off by default, lasts for this session, and Reset to Defaults turns it off.
- Ask Robi sees each app's file types and skips generic data formats. A short description comes from the Homebrew cask catalog, then the Mac App Store for apps installed there, then a curated list. Apps that match the task rank above apps that only share a category.
- Settings › About has an Acknowledgements card. It credits the Homebrew cask data under the BSD 2-Clause License.
