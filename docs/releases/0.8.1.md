DDock 0.8.1, Build 29.

## Verbesserungen

- Atmosphere: Fensterlicht hält bei fehlgeschlagenem Sample und zeigt sich im selben Fenster wieder.
- Accessibility: AX-Observer wird bei fehlgeschlagenem Create erneut versucht.
- App Fusion: Schließen des Pickers bricht die Discovery ab.
- Peek: Nach Tippen auf eine Karte wird Peek geschlossen.

## English

DDock 0.8.1, Build 29.

### Improvements

- Atmosphere: window light holds on a failed sample and can re-show in the same window.
- Accessibility: AX observer create is retried when it fails.
- App Fusion: closing the picker cancels discovery.
- Peek: dismisses after a card press.
