DDock 0.8.0, Build 28.

## Neue Funktionen

- App Fusion: Fenster koppeln per Kante, Dock-Icons, Peek oder Menü. Geteiltes Glas, Finder-Ordnerwerkzeuge, ein kombiniertes Dock-Paar.
- Atmosphere: Halo um das fokussierte Fenster. Intensität wie das Ambientlicht. Standardmäßig aus.
- Launcher: Liquid Glass aktualisiert nur geänderte Spring-Frames.

## English

DDock 0.8.0, Build 28.

### New

- App Fusion: pair windows from an edge dwell, dock icons, Peek, or the menu. Shared glass, Finder folder tools, one combined dock pair.
- Atmosphere: a halo around the focused window. Intensity matches the ambient wash. Off by default.
- Launcher: Liquid Glass updates only when the spring sample changes.
