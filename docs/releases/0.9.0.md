DDock 0.9.0, Build 31.

## Neue Funktionen

- Window Peek: optionale vergrößerte Vorschau (Einstellungen → Window Peek → Enlarged preview, standardmäßig aus). Bei Hover auf einer Karte öffnet sich eine Museum-/Lightbox-Ansicht mit Dim, Titelplakette und hochauflösender Aufnahme. Klick fokussiert wie bisher; Hover hebt das echte Fenster nicht an.

## English

DDock 0.9.0, Build 31.

### New

- Window Peek: opt-in enlarged preview (Settings → Window Peek → Enlarged preview, off by default). Dwell on a card opens a museum/lightbox hero with dim, title placard, and hi-res capture. Click still focuses as today; hover never raises the real window.
