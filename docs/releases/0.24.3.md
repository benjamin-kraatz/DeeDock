DOKK 0.24.3, Build 74.

## Verbesserungen

- Robi markiert seine Anweisungen bei Antworten mit Claude jetzt so, dass Claude sie zwischenspeichern und für die nächste Frage wiederverwenden kann, statt sie bei jeder Frage neu zu schreiben.
- Robi meldet jetzt, warum Claudes Zwischenspeicher eine Anfrage nicht wiederverwenden konnte. So lassen sich Kosten gezielter senken.
- Die Zählung der Ausgabe-Tokens umfasst jetzt die ganze Antwort, auch wenn Robi dabei ein Werkzeug benutzt hat.

## English

### Improvements

- When answering with Claude, Robi now marks its instructions so Claude can cache them and reuse them for the next question, instead of writing them again on every question.
- Robi now reports why Claude's cache couldn't reuse a request, so costs can be cut where it matters.
- Output token counts now cover the whole answer, even when Robi used a tool along the way.
