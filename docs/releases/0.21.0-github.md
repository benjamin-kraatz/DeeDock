DOKK 0.21.0, Build 65.

### New

- Lookout finds files by what's in them. Describe a photo, a screenshot, or a passage in your own words in the Hub's Files search, and Lookout finds the file whatever it is called. It reads documents, PDFs, images, and screenshots in the folders you choose, in more than 100 languages, on this Mac only. Set it up from the **Lookout off · Set up** chip in the Files search or under Settings → Lookout; the model downloads once and the Hub and Settings show the reading progress.
- Search with a picture: drag a picture onto the Hub, paste a screenshot with ⌘V, or choose **Find Similar** (⇧⌘L) on a file. Results show what looks like it and what is about the same thing.
- DOKK Islands split the dock into tinted glass blocks: the DOKK tile, pinned apps, running apps, and extras, with a frosted rim and a lit edge. Rename any island, pick its colour, or start a new island from a pinned app's menu. Pins keep their island when you reorder them. Islands are opt-in under Settings → Features → DOKK Islands, and a DOKK Discovery callout introduces them.
- In the Hub's Files tab, **Open in Right Pane** opens a folder beside the current one, and folder menus offer **Open in New Tab**.

### Improvements

- Lookout reads and verifies files and models off the shared thread pool, stops reading a picture when its search is cancelled, and searches again as soon as the first index appears.
