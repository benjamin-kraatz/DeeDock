DDock 0.4.1, Build 22, benötigt macOS 27 und einen Mac mit Apple Silicon.

## Neue Funktionen

- Das Update-Fenster kann künftig ein authored What’s-New-Comic anzeigen, wenn ein späteres Release eines neben den Notizen mitliefert.

## Verbesserungen

- Ohne Comic bleibt das bisherige Notizen-Verhalten unverändert.

## English

DDock 0.4.1, Build 22, requires macOS 27 and an Apple Silicon Mac.

### New

- The Update window can show an authored What’s New comic when a later release publishes one next to the notes.

### Improvements

- Without a comic, notes-only behavior is unchanged.
