DOKK 0.19.3, Build 63.

### New

- In the Hub's Files tab, you can add your own folders to the sidebar. Drag to the edge of a Favorites row or below the last one to create a slot. Right-click → Add to Sidebar (⌃⌘T) and Settings → DOKK Hub with Restore Default Places are included. Every Favorites row can be reordered or removed; removal offers Undo. Bookmarks follow renames and moves in Finder; deleted or disconnected folders are marked.
- Breadcrumb segments above a Files pane accept drops and spring-load like Finder's path bar. Option copies; another volume always copies.
- Middle-click closes a browser tab in Files. Releasing outside cancels; the last tab stays open.
