DDock 0.6.1, Build 25, benötigt macOS 27 und einen Mac mit Apple Silicon.

## Fehlerbehebungen

- Launcher: Esc beendet Robi, bevor das Panel schließt.
- Launcher: Dateien wählen bricht Robi ab.
- Launcher: Browse-Scroll-Identität enthält den Ortsfilter.
- Updates: Hinweise verschwinden, sobald irgendein Update-Fenster sichtbar ist.
- Updates: offenes Window Peek zählt als beschäftigt für die Installation im Leerlauf.

## English

DDock 0.6.1, Build 25, requires macOS 27 and an Apple Silicon Mac.

### Fixes

- Launcher: Esc exits Robi before closing the panel.
- Launcher: Choose Files cancels Robi.
- Launcher: browse-scroll identity includes the location filter.
- Updates: awareness clears when any Update window is shown.
- Updates: an open Window Peek counts as busy for idle install.
