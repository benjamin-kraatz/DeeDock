DDock 0.4.0, Build 21, benötigt macOS 27 und einen Mac mit Apple Silicon.

## Neue Funktionen

- Magnetische Kanten: Pins und Ordnerstapel rasten an Bildschirmkanten und aneinander ein, während du sie ziehst.
- Optionale Seifenblasen-Effekte beim Anklicken, Anheften und Ablegen von Apps (standardmäßig aus; Reduce Motion lässt sie aus).
- Pin-Wetter / Icon-Rost: ungenutzte Pins bekommen mit der Zeit einen leichten Rost und werden beim erneuten Nutzen wieder sauber.
- Atmosphere: optionale Ambiente-Lichteffekte für das Dock, inkl. Intensitätsregler.
- Clipboard Museum: lokale Zwischenablage-Historie am Dock.
- Quarantäne-Stempel: Kennzeichnung von Apps aus der Quarantäne.
- Lokale Feature-Tipps (Discovery), inkl. Hinweis auf das Clipboard Museum.
- System Settings Clone: durchsuchbares Springboard / Concierge-Fenster für Systemeinstellungen.

## Verbesserungen

- Niedrigerer Idle-CPU und weniger Finder-Wakeups.
- Magnetisierte Pins bleiben beim Loslassen geparkt statt entpinnt zu werden.

## English

DDock 0.4.0, Build 21, requires macOS 27 and an Apple Silicon Mac.

### New

- Magnetic edges: pins and folder stacks snap to screen edges and to each other while dragging.
- Optional soap-bubble effects on app click, pin, and drop (off by default; Reduce Motion keeps them off).
- Pin Weather / icon rust: unused pins gently rust over time and clean up when used again.
- Atmosphere: optional ambient dock lighting, including an intensity slider.
- Clipboard Museum: local clipboard history at the dock.
- Quarantine stamp: marks quarantine’d apps.
- Local feature tips (Discovery), including a Clipboard Museum suggestion.
- System Settings Clone: searchable springboard / concierge window for System Settings.

### Improvements

- Lower idle CPU and fewer Finder wakeups.
- Magnetized pins park on release instead of unpinning.
