DOKK 0.19.0, Build 60.

### New

- The DOKK tile opens the DOKK Hub, a glass panel above the dock. The tabs "Apps", "Windows", and "Files" switch with Command-1, Command-2, and Command-3. Each tab keeps its own search, and Command-F focuses the search field. The Hub reopens on the tab it showed when it last closed. Click the tile, press Return in Focus Dock, or use its VoiceOver action to open it. The dock stays in place.
- "Keep open as a window" detaches the Hub from the dock and makes it a normal window. You can move it and resize it down to 900 by 500 points, and it stays open after you open an app, a window, or a file. "Attach to the dock" puts it back above the tile. The Hub remembers whether it was detached, and the window's frame.
- The "Apps" tab is the launcher. It holds suggestions, the app grid, mixed search, Robi, and file actions. Files dropped on the tile or on the open tab open that tab for a file action. The "Compact" and "Full" styles, and the setting for them under Settings › Dock › Appearance › Launcher, are removed. "Line icons in Launcher" is now "Line icons in the Hub's Apps tab".
- The "Windows" tab shows open windows grouped by app, with a thumbnail and a title. "Open Radar" starts Radar. Screen Recording supplies the thumbnails. Accessibility shows minimized windows and windows of hidden apps, and brings one exact window forward. If a permission is missing, a hint with "Open System Settings" sits under the summary. Without Screen Recording, a card shows the app icon. Without Accessibility, a click activates the app instead of one window. Windows on other Spaces are left out. Minimized windows and windows of hidden apps still appear.
- The "Files" tab is a small file browser with browser tabs, Split View, the List, Icons, and Columns views, a preview, Quick Look, and a Spotlight search of names, on This Mac or in the current folder. Drives show free space. External disks, disk images, and network volumes can be ejected. The startup disk cannot. Dragging follows Finder. A drop on the same volume moves the items, a drop on another volume copies them, and Option always copies. The queue runs one job at a time. Pause, Resume, and Cancel apply to the running job, and the queue keeps going after the Hub closes. A progress ring on the DOKK tile then shows how far it is. Folder stacks, Downloads, and drives offer "Open in Hub". "Reveal in Finder" stays in the Hub.
- On a dock with app icons, the DOKK tile draws the Glow artwork, the white DOKK mark on a dark face, with a rainbow halo. The halo brightens and grows while the Hub is open. In the "Line" style, the glyph stays lit while the Hub is open. Reduce Motion fades the Hub in and out without scaling or moving it, and holds the halo still. Reduce Transparency draws an opaque background instead of glass.
- macOS asks for access the first time the Files tab reads Desktop, Documents, or Downloads. File search finds only names in the Spotlight index, not file contents, and at most 200 results. Folders Spotlight skips return nothing, and the tab does not say why. The Hub has no global keyboard shortcut. Copy, Paste, Duplicate, and Undo are not in the Files tab yet. Drag with Option held to copy.
- Usage analytics count how often the Hub opens, which tab is selected, whether it is detached as a window, and file transfers by count and outcome. File names, paths, search text, window titles, and app names are not sent.
