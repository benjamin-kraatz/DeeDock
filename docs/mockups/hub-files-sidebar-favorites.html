DEE-128 — folders in the Hub's Files sidebar. Drag any folder from the list into the sidebar. Over the middle of a row it still means "move into". At a row's top or bottom edge, a slot opens and the drop adds the folder there. The dashed end slot appears as soon as you drag a folder. Right-click a folder → Add to Sidebar, or select one and press ⌃⌘T. Right-clicking the empty list area adds the folder you're in. Drag added rows to reorder. Drag one out of the sidebar to remove it, or right-click it, then ⌘Z or Undo. ⌘- or ⇧-click selects several items. Hold ⌥ while dropping to copy. The defaults are the choices locked on 2026-10-14. The ? toggles show the alternatives that were considered.

What to look at

  1. Drop zones. On a row, the top and bottom quarter insert and the middle half moves into the folder. A drag with only files never inserts. Packages such as DeeDock.xcodeproj and apps are never added.
  2. Insert indicator. The preview row shows exactly what you'll get. The line is Finder's look. Rows part on the Hub spring in both styles.
  3. End slot. A dashed "Add folder here" row appears at the end of the list as soon as a folder drag starts. This is how people find the feature. Turn it off to compare.
  4. Arrival. Added from the menu or ⌃⌘T: the folder icon arcs into its new row. Added by drag: the row settles out of the drag image. Either way it glows once in the accent color. Reduce Motion skips the flight, the glow, and the spring.
  5. Duplicates. Adding a folder that's already there moves it to the drop position (drag) or pulses the existing row (menu or ⌃⌘T). The menu offers Remove from Sidebar instead of Add.
  6. States. Try the scenarios. A deleted folder dims and shows ⚠. A folder on an ejected drive reads "Transfair nicht verbunden" and comes back when the drive is mounted again. Renamed folders follow, because rows are stored as bookmarks. Two folders with the same name get their parent folder as a subtitle.
