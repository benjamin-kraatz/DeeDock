DOKK Plugins interactive mockup · DEE-140

What this is. Plugins are small extensions that ship inside other apps. DOKK lists them, the user turns each one on once in a system window, and each pinned plugin gets a tile. Clicking the tile opens the plugin's panel, anchored like the Notification Feed. Everything under the panel's header is drawn by the plugin in its own process. DOKK draws the glass, the header, the pointer, and the stopped state. Try it: click a plugin tile, right-click a tile, press Re-run in Build Status, press Bump badge in the Sample plugin, then Simulate plugin crash. Switch to Settings and press Manage Plugins… to approve the waiting plugin.

  1. Placement A. Plugins get their own dock section between apps and DOKK's own tiles. With DOKK Islands on, that section is its own island.
  2. No plugin mark. Plugin tiles look like any other tile. The "Corner badge" control is kept only for comparison.
  3. Panel size. The plugin asks for a content size. DOKK adds its 40 pt header and the 10 pt pointer, and keeps the panel between the popover minimum of 280×220 and the popover default of 560×420, on screen with a 16 pt margin.
  4. Settings. Plugins get their own sidebar section with the puzzle-piece symbol. Dock Extras moves to a different symbol.
  5. Newly approved plugins are pinned automatically at the end of the plugin section. They can be unpinned from the tile menu or in Settings.
  6. Stopped state. A grey tile with a small restart chip, and the stale badge hidden. The panel shows a calm "stopped · Restart" in place, never an alert.
  7. Waiting plugins appear only in Settings, never in the dock.
