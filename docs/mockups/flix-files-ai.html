Reading the window in front

  1. Accessibility: the window's text tree, through Robi's reader. Fast and exact.
  2. Too little text? Vision recognizes the text in a capture of that one window (Screen Recording, already granted for Peek).
  3. Still too little (icons, canvas UIs)? Apple Intelligence looks at the window image itself.

Every path ends in Apple Intelligence turning the text into what the window wants: which files, plus limits like "PDF only, max 5 MB". Runs once per open, cached until the window changes. Switch Its text is above to watch each step.

Where each feature runs

  • Lookout: search by meaning, Threads grouping, Versions, More like this, folder suggestions.
  • Apple Intelligence: sentence → filters, Thread names, captions, renames, key facts, Smart Filters from a sentence, Where was I?, sensitive check (with Vision), window reading.
  • Robi: Ask about these files.
  • Local counts: drag memory and filter tips.

Cost and fallbacks

  • Captions, names, facts and the sensitive check run once per file in the background, cached by content. Never during a drag or pointer movement.
  • Without Lookout: search falls back to names, and Threads group by time and folder only. Without Apple Intelligence: no captions or names, plain search filters. Flix itself always works.
  • Analytics count feature use only. No names, paths, or text.
