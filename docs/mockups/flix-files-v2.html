What changed from v1

  • Grab, not search. The main gesture is dragging the newest thing into an upload form, a mail, a chat. Search stays, but hides behind ⌘F or just typing.
  • Activity, not just "recently opened". Downloads (with the site they came from), new screenshots, saved and changed files, folders, apps.
  • Home is the dock. A live tile with the newest item's thumbnail and a "new since you looked" badge. Drag the tile to carry that item. The menu bar is optional.
  • Sidebar instead of chips. Activity types, kinds, Smart Filters (v1 collections become saved filters with an icon), and Favorites that accept drops.
  • The panel steps aside. Drag a row out of it and it fades so you can reach what's underneath. It comes back only if pinned.

Data sources (public API)

  • Opened: Spotlight kMDItemLastUsedDate via a live NSMetadataQuery.
  • New / changed: FSEvents with file-level events on the watched folders. DOKK needs folder access, the same prompts Lookout already handles.
  • Downloaded: new in Downloads, with the source from kMDItemWhereFroms.
  • Screenshots: kMDItemIsScreenCapture.
  • Apps: NSWorkspace activation notifications.
  • DOKK keeps its own history (capped, per-item Remove). Spotlight only feeds it.
