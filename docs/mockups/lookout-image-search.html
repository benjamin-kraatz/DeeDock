Lookout: search with a picture. Drag one of the pictures on the right edge of the desktop onto the Hub. The search field opens up as a drop target, and dropping searches with that picture. The zip file shows what happens with something that isn't a picture. You can also press Copy a picture below and then ⌘V in the search field. For a file already in the index, select it and press Find Similar, right-click it, press ⌘⇧L, or drag the row onto the search field. ⌫ on the picture chip goes back to your previous words. Typing starts a new search by words.

Searching with a picture. The search uses meaning only. There are no words, so the Names section doesn't appear. Lookout already scores pictures and documents on separate scales, so results arrive in two groups, each with its own strong ratio: Looks like it (pictures) and About what it shows (documents). Starting from a document, the groups become Says something similar and Pictures of it. Find Similar on a file already in the index reuses that file's stored vector, so the result is instant. A picture you drop or paste is read in memory only and never saved. The query service loads its picture reader only when you search with a picture: the first time takes about 1.2 s, later searches about 0.35 s, and it unloads 2 minutes after the last search, like the rest of the query service. The file you searched with never appears in its own results. Analytics would add lookout_image_search (source: drop, paste or similar; cold start yes or no) and a query: text | image property on lookout_result_opened. They never include the picture, a name or a path.

Ranking math is DigUp's Searcher: meaning is a per-query z-score (gate z ≥ 2.0); words add 2 × coverage^1.5; a lookup query (codes and long numbers) flips to 0.5 × z + 4 × coverage^1.5; a kind word ("photo", "screenshot") adds 1. Rows below strong ratio × the top score fold under “Weaker matches”. A folder qualifies when three or more of its files match; it scores the average of its three best files plus 0.25 for each further match (up to +1). That folder rule is a DOKK proposal, not DigUp's. All files, scores and timings here are sample data.
